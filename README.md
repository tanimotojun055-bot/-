1. 研究の目的

私は現在、軽自動車などを利用して、限られた空間で実際に生活する実験を行っている。

車内で睡眠を取り、食事をし、簡単な調理を行い、パソコンやAIを利用して研究活動を続けている。

この実験には、将来の宇宙船や月面基地、火星基地など、限られた居住空間で人間が長期間生活するための条件を調べるという目的がある。

宇宙空間では、居住容積、電力、水、空気、食料などの資源が制限される。

そのため、限られた資源を利用して、人間が安全かつ快適に生活できるシステムを構築する必要がある。

私は、その基礎的な問題を実生活の中で検討している。

---

2. 居住空間の大きさについて

軽自動車では空間が不足する

実際に軽自動車で生活してみると、日本の最近の軽自動車は室内空間がよく工夫されているものの、長期的な生活には狭すぎることがわかった。

特に問題になるのは、次の点である。

- 身体を十分に伸ばすことが難しい。
- 長時間同じ姿勢で過ごすことになる。
- 睡眠、食事、作業の空間が重複する。
- 荷物や機材が居住空間を圧迫する。
- 長時間動かずに過ごすことによる健康上の問題が生じる。

長時間身体を動かさない生活は、深部静脈血栓症、いわゆるエコノミークラス症候群の危険因子にもなる。

必要な居住空間

今回の経験から、軽自動車の居住空間を基準として、約1.5倍程度の余裕が欲しいと考えている。

シトロエンの比較的大きな車両や、ポルシェ・カイエンのようなSUVの室内空間が、一つの参考になる。

ただし、1.5倍という数値は、現時点では実生活から得た感覚的な目安であり、厳密な設計値ではない。

重要なのは、単なる車体寸法ではなく、実際に生活に使える空間の大きさである。

小空間居住では、最小容積を追求するだけでなく、人間が身体を動かせる余裕を確保することが必要である。

3. 車内調理に関する実験

私は車内で実際に調理を行い、調理方式による違いを調べている。

使用・検討している調理器具には、次のものがある。

- カセットガスコンロ
- 12V電源式湯沸かし器
- 電子レンジ
- 電気抵抗式の加熱器

3-1. ガスコンロの問題

車内でカセットコンロを使用すると、大きな問題になるのが排熱である。

私は換気ファンを使用し、強制排気を行っている。

しかし、それでも焼肉などの調理をすると、車内に大量の熱が蓄積する。

原因は、空気を排出しても、赤外線による放射熱や、内装材に蓄積された熱まで直ちに排出できるわけではないからである。

さらに、燃焼によって酸素が消費され、二酸化炭素や水蒸気が発生する。不完全燃焼では一酸化炭素も発生する。

強制換気を行っても車内でのガス調理の安全は保証できず、一酸化炭素中毒や火災の危険がある。

したがって、将来の閉鎖型居住施設では、燃焼を伴わない調理方式が必要である。現在の車内調理についても、燃焼調理は車外で行う方が安全である。

3-2. 電子レンジの問題

以前、キャンピングカーで電子レンジを使用していた。

当時は100Ah程度の鉛バッテリーを利用していたが、冷凍食品の解凍と加熱に電子レンジを使用すると、短時間で電源が使用できなくなることがあった。

例えば、完全に凍結した約500gの冷凍ピラフを加熱する場合などである。

電子レンジは消費電力が大きく、鉛バッテリーから大電流を取り出すため、電圧降下や実効容量の低下が問題になる。

また、マグネトロン方式では、電気エネルギーからマイクロ波への変換損失も存在する。

この経験から、バッテリー容量の限られた環境では、電子レンジの使用を短時間の加熱に限定することが望ましいと考えた。

例えば、冷めた食品の短時間の温め直しには使用できるが、大量の冷凍食品の解凍には別の方法を検討する必要がある。

3-3. 12V電気加熱方式

私は12V電源式の湯沸かし器も所有している。

これを利用すれば、次のような用途に対応できる。

- 飲料用のお湯を作る。
- コーヒーを入れる。
- カップ麺を作る。
- 湯せん対応食品を温める。

電子レンジとは異なり、比較的小さな電力で時間をかけて加熱できる。

ただし、必要な熱量そのものが減るわけではない。

特に重要なのは、蓄電池に大きな電流負荷をかけないことである。

また、冷凍食品は適切な温度管理のもとで事前に解凍しておくことで、食事の直前に必要な電力を減らせる。

4. カーボン系発熱体の可能性

将来の小空間居住では、調理器具の改良が重要になる。

従来のニクロム線による抵抗加熱に加え、現在はさまざまなカーボン系発熱体が利用できる。

例えば、

- カーボン厚膜発熱体
- カーボン系面状ヒーター
- PTCセラミック発熱体
- セラミック基板を利用した抵抗発熱体

などである。

抵抗発熱方式では、電気エネルギーのほぼすべてが最終的に熱になる。

ただし、その熱を食品や水へどれだけ効率よく伝達できるかは、発熱体の形状や断熱構造によって変わる。

カーボン系材料には赤外線の放射率が高いものもあり、放射加熱に利用できる。

一方、水を温める場合には、放射率だけでなく、容器と発熱体の接触状態や熱伝導も重要になる。

今後は、こうした発熱体を用いた小型調理器具の研究を検討したい。

5. 省電力の植物栽培実験

私は以前、研究所の小屋で水耕栽培の実験も行った。

中古販売店で、もともと高額だった水耕栽培キットを約1万円で購入し、実際に使用した経験がある。

その際、積算電力計を使用して消費電力量を測定した。

問題はモーターの消費電力だった

購入した装置には、モーターを利用したファンなどが組み込まれていた。

これらを長時間動作させると、積算消費電力量が大きくなった。

そこで、低消費電力で作物を育てるには、モーターを常時運転する方式を見直す必要があると考えた。

今後は、

- 自然光を最大限利用する。
- 不足する光量をLEDで補う。
- 夜間のLED補光を検討する。
- 水の循環に必要な電力を削減する。
- 可能な場合は無動力式の水耕栽培を利用する。

という方針で実験したい。

特に、LED照明による夜間補光は、栽培期間の短縮や収穫量の増加につながる可能性がある。

ただし、その効果は植物の種類、照射強度、照射時間などによって異なる。

重要なのは、消費電力量に対して、どれだけの食料を生産できるかということである。

6. 小型ビニールハウスの活用

私は中国の通販サイトで、約2万円の小型ビニールハウスキットも購入している。

当初は高島研究所での利用も考えたが、高島は積雪が多く、簡易構造のビニールハウスでは雪の荷重によって破損するおそれがある。

そこで、和歌山県の生石研究所に持ち込み、設置することを考えている。

生石研究所でも積雪や強風への対策は必要だが、自然光を利用する小規模な植物栽培実験施設として活用する計画である。

将来的には、低消費電力の水耕栽培方式と組み合わせたい。

7. 閉鎖型居住施設では資源循環が必要になる

私は将来、地球上の厳しい気候環境だけでなく、月面基地や火星基地などでも生活できる居住システムの開発を考えている。

そこでは、食料、水、空気、エネルギー、機械部品などを、できるだけ施設内部で再利用する必要がある。

特に宇宙では、故障した部品を簡単に買い替えたり、廃棄物を外へ捨てたりすることはできない。

そのため、現在の研究所では、将来的に次のような設備も整えたいと考えている。

金属材料の再利用

陶芸用電気炉の構造を参考に、小型電気炉を自作する。

用途としては、

- 金属の熱処理
- 金属粉末の焼結
- 3Dプリンターによる金属部品の製作
- 廃金属の再利用
- 補修部品の製作

などを想定している。

鉄鋼の溶解には一般的な陶芸炉より高い温度が必要になるため、目的に応じて炉の構造を設計する必要がある。

物を修理して使い続ける技術

私は以前から、自動車や機械の修理を自分で行っている。

クラシックカーなどでは、すでに補修部品が製造されていないことも多い。

そのため、部品を交換するだけではなく、修正、再加工、再製作する技術が重要になる。

ただし、ブレーキや操舵系などの重要保安部品では、必要な強度や安全性の確認が不可欠である。

こうした技術は、将来の宇宙基地でも必要になると考えている。

---

8. 月面基地・火星基地への応用

月面や火星では、地球とは異なる環境条件に対応する必要がある。

月面基地

月面では、長期間の日照と夜間、極端な温度環境への対応が必要になる。

限られた電力を有効利用するためには、蓄電、蓄熱、断熱、省電力設備が重要になる。

火星基地

火星では、大気圧が低く、寒冷な環境や大きな昼夜の温度差への対応が必要になる。

植物栽培や居住施設の維持には、断熱と熱管理が不可欠である。

また、どちらの基地でも、水や空気を循環させる生命維持システムが必要になる。

今回の車内生活実験は、こうした大規模な技術を直接実証するものではないが、限られた空間と電力で人間が生活する際の課題を知るための基礎的な経験となっている。

---

9. 今回の車内生活実験から得られた結論

今回の生活経験から、私は次のように考えるようになった。

第一に、居住空間は小さければよいというものではない。

人間が健康的に生活し、睡眠、食事、作業を行うためには、十分な余裕が必要である。

第二に、限られた電力を有効利用することが重要である。

電子レンジなどの大電力機器を長時間使用することは、小規模な蓄電設備に大きな負担をかける。

第三に、熱管理と空気管理は別々に考える必要がある。

換気を行っても、放射熱や内装材に蓄積された熱を十分に除去できるとは限らない。

第四に、食料生産にもエネルギー効率の検討が必要である。

作物を栽培できることと、限られた電力で継続的に食料を生産できることは別の問題である。

第五に、修理と資源の再利用が重要になる。

部品の交換だけに依存せず、修復や再製作が可能なシステムを構築する必要がある。

10. 今後の研究方針

今後は、これまでの経験をもとに、次の研究を進めたい。

1. 小空間居住に必要な最低限の寸法と快適性の評価
2. 12V・24V電源による低消費電力調理システム
3. カーボン系発熱体を利用した加熱技術
4. 断熱・蓄熱・排熱システム
5. LED補光と無動力式水耕栽培
6. 金属3Dプリンターと小型焼結電気炉
7. 廃棄物・金属材料の再利用
8. AIによる居住環境の自動管理
9. 将来の閉鎖型居住施設への応用

最後に

私が車内で食事を作り、寝泊まりし、パソコンで研究を続けていることは、外から見れば単なる車中泊に見えるかもしれない。

しかし、実際に限られた空間で生活することで、設計図や理論だけではわからない問題が見えてくる。

私は将来、自分で宇宙船を開発し、宇宙へ飛び立つことを目標の一つとしている。

そのためにも、まず地球上で、限られた空間、エネルギー、資源を使って生活するとはどういうことなのかを知る必要がある。

実際に生活して問題を発見し、測定し、改善する。

その積み重ねが、将来の閉鎖型居住システムや宇宙居住技術の研究につながると考えている。
